# شعله — ردیاب عادت‌های روزانه

یک اپ ساده و سریع برای دنبال کردن عادت‌های روزانه، دیدن رکورد پیاپی (streak) و پیشرفت روزانه. بدون بک‌اند، بدون نیاز به اینترنت — همه‌چیز توی مرورگر خودت با `localStorage` ذخیره می‌شه.

## ویژگی‌ها

- افزودن و حذف عادت‌های دلخواه
- علامت زدن انجام‌شدن هر عادت برای ۷ روز اخیر
- محاسبه‌ی خودکار رکورد پیاپی (streak) هر عادت
- نمایش درصد پیشرفت امروز
- حالت روز/شب با یادآوری انتخاب قبلی
- ذخیره‌سازی کامل روی مرورگر (بدون سرور)

## اجرا

هیچ نصب یا build نمی‌خواد. کافیه فایل `index.html` رو مستقیم توی مرورگر باز کنی، یا با یه سرور ساده اجرا کنی:

```bash
python3 -m http.server 8000
# سپس مرورگر رو باز کن روی http://localhost:8000
```

یا با افزونه‌ی Live Server توی VS Code.

## ساختار پروژه

```
habit-tracker/
├── index.html   # ساختار صفحه
├── style.css    # طراحی و تم روز/شب
├── script.js    # منطق اپ (ذخیره‌سازی، محاسبه‌ی streak، رندر)
└── README.md
```

## تکنولوژی

فقط HTML، CSS و JavaScript خالص — بدون فریم‌ورک، بدون وابستگی build.

## ایده‌های توسعه بعدی

- Export/Import داده‌ها به فایل JSON
- نمودار ماهانه به‌جای فقط ۷ روز اخیر
- یادآوری با Notification API
- همگام‌سازی بین دستگاه‌ها با یه بک‌اند ساده
